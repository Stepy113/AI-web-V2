# Můj AI Web: The Last of Us Part II

Tento projekt vznikl jako školní úkol zaměřený na efektivní komunikaci s umělou inteligencí (promptování). Web byl vygenerován a sestaven za asistence AI modelu Gemini od Googlu.

## Co projekt obsahuje:
- Hlavní stránku (index.html) s informacemi o projektu a citacemi AI.
- Podstránku s popisem příběhu (o-hre.html).
- Galerii s obrázky ze hry (galerie.html).
- Jednotný temný design pomocí externího CSS (style.css).

Vytvořeno v roce 2026.
